# Release v2.0.0

## Overview

v2.0.0 introduces a redesigned file selection model with explicit, composable filter rules and a new pick mode for direct file addressing.

## Breaking Changes

### Filter flags are now ordered — last match wins

The previous `--include` / `--exclude` precedence model has been replaced with an ordered evaluation model. Flags are evaluated in the order they appear on the command line and the last matching rule wins.

**Before:**

```bash
# --exclude was always final
snp --include "**/*.go" --exclude "**/*_test.go"
```

**After:**

```bash
# Last match wins — order matters
snp --include-all --exclude-defaults --exclude "**/*_test.go"
```

### `--no-defaults` removed

Replaced by explicit baseline flags.

## New Features

### Baseline flags

Three new flags set the starting state for traversal:

```
--include-all         Include all files
--exclude-all         Exclude all files
--exclude-defaults    Exclude default patterns and .gitignore
```

The implicit default behavior is unchanged:

```bash
snp  # equivalent to: snp --include-all --exclude-defaults
```

### Composable filter rules

Baseline and filter flags can be freely interleaved:

```bash
# Only Go files
snp --exclude-all --include "**/*.go"

# Everything except tests, rescue one specific test
snp --include-all --exclude-defaults --exclude "**/*_test.go" --include "internal/auth/auth_test.go"
```

### Pick mode — direct file addressing

New `--pick` flag for addressing files directly without traversal:

```bash
# Exact files
snp --pick "cmd/main.go" --pick "README.md"

# Glob patterns
snp --pick "internal/**/*.go"

# Cross-repo from parent directory
snp --pick "repo-a/cmd/main.go" --pick "repo-b/cmd/main.go"

# Absolute paths
snp --pick "/etc/nginx/nginx.conf"
```

`--pick` cannot be combined with traversal flags.

### `--show-defaults`

Print the default exclude patterns:

```bash
snp --show-defaults
```

### Automated GitHub releases

Pushing a version tag now triggers automated release builds via GitHub Actions. Release notes are picked up from `.release-notes/<tag>.md` if present.
