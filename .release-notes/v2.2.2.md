# Release v2.2.2

## Overview

v2.2.2 fixes a crash when a snapshot run encountered a zero-byte file (e.g.
`.gitkeep`), and corrects binary-file accounting in the summary and index.

## Bug Fixes

### Empty files no longer abort the run

Binary detection read 512 bytes to sniff content type. On a zero-byte file
this returned `io.EOF`, which was treated as a fatal error and aborted the
entire snapshot with `snp: EOF`. Empty files are now correctly classified as
non-binary, and are rendered in the content section as `[Empty file]`.

### Binary files now counted correctly

`IsBinary` was never assigned on file entries. Binary files were reported as
text in the summary (`Total files: N (N text, 0 binary)`) and received a line
range in the file index instead of the binary metadata line.
