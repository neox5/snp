# Release v2.1.0

## Overview

v2.1.0 is a significant internal redesign that introduces configuration
persistence, output section control, a purpose-built snapshot pipeline, and
stdout support for agent and pipe workflows.

## New Features

### Configuration file (.snpconfig.json)

Flags can now be persisted to `.snpconfig.json` in the source directory.
Config file flags are merged with CLI flags at runtime; CLI flags take
precedence.

```bash
snp --exclude-all --include "**/*.go" --save-config
snp --show-config
snp --no-config
```

### Output section control

New `--no-<section>` flags omit individual sections from the snapshot output:

```
--no-summary      Omit summary section
--no-index        Omit file index section
--no-git-log      Omit git log section
--no-content      Omit file content sections
```

New `--only-<section>` flags select individual sections, suppressing all
others. Flags are composable — multiple `--only-x` flags include all named
sections:

```
--only-summary    Include only summary section
--only-index      Include only file index section
--only-git-log    Include only git log section
--only-content    Include only file content sections
```

### --stdout

Write snapshot content to stdout instead of a file. All status and diagnostic
output is redirected to stderr, enabling clean pipe and agent workflows:

```bash
snp --only-index --stdout 2>/dev/null | grep "\.go"
snp --only-content --stdout > content.txt
```

### --depth flag

Limit directory traversal depth:

```bash
snp --depth 0   # root files only
snp --depth 2   # two levels deep
```

### Verbosity flags

```bash
snp -v    # verbose: show resolved config
snp -vv   # debug: show matcher rules
```

## Improvements

### Purpose-built snapshot pipeline

Internal rewrite of the snapshot package into a structured
collect → process → layout → write pipeline. Buffered I/O throughout
for improved performance on large codebases.

### Purpose-built pattern matching

Replaced the `go-gitignore` dependency with a purpose-built matcher package.
Consistent gitignore-style matching across all pattern types including
`*.test.js` and `**/*.test.js` at any depth.

### Output stream consistency

Status and diagnostic output is uniformly written to stderr. Snapshot content
goes to stdout (with `--stdout`) or to the output file. Internal methods
accept `io.Writer` throughout, enabling clean separation in all execution
paths.
